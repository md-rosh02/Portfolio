(01) AboutStory so far

The partpeople touch.

I'm a Computer Science graduate who is happiest working on the layer of software that people actually see and use — the interface.

I earned my B.E. in Computer Science from Rural Engineering College, Hulkoti in 2025. Along the way, web development is where curiosity turned into craft: first HTML, CSS and JavaScript, then React.js and Tailwind CSS.

My internship at Tech Fortune Technologies put that into practice on an e-commerce website — building pages, refining layouts, testing, and fixing errors alongside a team.

I aim for interfaces that are simple, responsive and consistent, built from reusable components. I like problem-solving, I'm a quick learner, and I want to get a little better at this every single week.
